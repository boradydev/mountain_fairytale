# Адрес сервера в Windows-приложении

В верхней панели нажмите шестерёнку **«Настройки приложения»**. Кнопка доступна
в основном окне, на экране входа и при недоступности сервера. Открытые редакторы,
формы и окно обновления сначала нужно закрыть.

1. Введите полный адрес, например `http://192.168.0.26:8000`. Разрешены HTTP/HTTPS,
   IP или имя сервера. Не добавляйте `/app/v1`, `/public`, логин, пароль или параметры.
2. Нажмите **«Проверить соединение»**. Проверяется `/health/ready` без токенов входа,
   с таймаутом 5 секунд. При успехе показывается версия сервера. Проверка не меняет
   текущее подключение и ничего не сохраняет.
3. Нажмите **«Сохранить»** и подтвердите смену сервера. Если проверка ещё не выполнена
   для этого адреса, она выполнится перед сохранением. Недоступный адрес можно
   сохранить после дополнительного подтверждения: VM может быть выключена.
4. При изменении URL приложение очищает сохранённый вход, закрывает прежнее сетевое
   подключение и сбрасывает данные сессии. Войдите на новом сервере заново.

Адрес хранится в настройках текущего Windows-пользователя (`api_server_url`),
сохраняется после перезапуска и обновления приложения. На другом ПК его нужно
указать отдельно. Если URL не изменился, сохранение не завершает сессию.
При ошибке очистки токенов или сохранения настроек сервер не переключается.

**«Вернуть адрес по умолчанию»** подставляет адрес из сборки в поле; чтобы применить
его, нужно отдельно сохранить и подтвердить. **«Отмена»** оставляет текущий адрес.

`--dart-define=API_BASE_URL=...` / GitHub Actions Variable задаёт только начальный
адрес и значение кнопки возврата. Сохранённый адрес имеет приоритет. Его изменение
не требует новой сборки или релиза. Старые установленные версии без шестерёнки
нужно один раз обновить до версии с этой возможностью.

На Ubuntu новый IP по-прежнему настраивается вручную: изменить `API_BIND_HOST`
в серверном `.env`, применить firewall, пересоздать API из прежнего образа и
проверить подключение с Windows. Настройки Flutter не меняют сеть или `.env` VM.
