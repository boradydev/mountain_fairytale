# Репетиция обзвона клиентов — 28 октября 2026

Окружение: локальный Flutter и API 127.0.0.1:8001, база репетиции.
Пользователь запросил совместное ручное тестирование обзвона.

## Исходное состояние

Через API проверены три активных клиента: ООО Высота, Тест — Борис,
Тест — Анна. У всех последний заказ 28.10.2026, порог 7 дней,
отсрочки нет. В текущий день они не должны попадать в обзвон.

Через штатный POST /protected/clients/create создан отдельный активный
клиент «Тест — Обзвон», телефон +79990000071, адрес Михайловск,
Тестовая 71, порог 7 дней. Заказов и отсрочки нет. Запись повторно
прочитана через GET по ID и проверена. ID записан в игнорируемом
backend tmp/operations/ux-followup-client.json. Прежние клиенты и
документы не изменялись. Заказы агентом не создавались.

## Сценарий

1. Дашборд → «Обзвон клиентов»: появляется «Тест — Обзвон» с подписью
   «Заказов не было», остальные три клиента не показаны.
2. Меню контакта → отложить на неделю: клиент исчезает из обзвона;
   в базе остаётся с отсрочкой до 04.11.2026.
3. Сбросить отсрочку из базы: клиент возвращается в обзвон.
4. Проверить произвольную дату отсрочки из редактора и её сброс.
5. Оформить обычный тестовый самовывоз: после заказа клиент перестаёт
   попадать в обзвон при пороге 7 дней; последний заказ читается из API.
6. Дополнительно по ходу репетиции проверить влияние отмены/восстановления
   этого заказа и деактивации клиента на очередь.

Ручные результаты фиксируются после подтверждения пользователя.

## Подтверждённые результаты

- В обзвоне показан только «Тест — Обзвон»; клиенты с сегодняшними заказами
  и порогом 7 дней отсутствуют.
- Отсрочка на неделю убрала клиента из обзвона. Сброс из базы вернул его.
- Пользователь создал сегодняшний самовывоз на 1 бутылку / 350 ₽:
  клиент исчез из обзвона, в базе зелёный статус «Заказывает регулярно».
- После отмены этого самовывоза клиент снова красный и виден в обзвоне.
- После восстановления самовывоза клиент снова исключён из обзвона,
  статус в базе зелёный. Все перечисленные действия подтверждены пользователем.
- Пользователь выбрал в карточке отсрочку до 31.10.2026: статус изменился
  на отложенный контакт, клиент оставался вне обзвона. Выбор даты оценён
  как удобный и понятный. После сброса вернулся зелёный статус
  «Заказывает регулярно»; клиент вне обзвона из-за сегодняшнего заказа.
- Базовый сценарий обзвона завершён, замечаний пользователя нет. Прогресс
  дней до порога и смена цветов по истечении времени в этом ручном прогоне
  не имитировались. Деактивация клиента в рамках этого прогона не выполнялась.
- Итог: «Тест — Обзвон» активен, порог 7 дней, отсрочка сброшена,
  пользовательский самовывоз на 350 ₽ восстановлен и активен.
