Mountain Fairytale 1.1.0

- Добавлена проверка совместимости приложения с сервером при запуске и во время работы.
- Если сервер требует более новую версию, приложение показывает экран обязательного обновления. Несохранённые данные форм сбрасываются; сохранённые документы остаются на сервере.
- На экране обновления доступны смена темы, обновление приложения, повторная проверка, настройки подключения и закрытие.
- В меню приложения показываются версия приложения, версия сервера и минимальная поддерживаемая версия клиента.

Для этого выпуска сначала установите backend 1.0.0. Совместимые версии приложения по-прежнему обновляются добровольно.
