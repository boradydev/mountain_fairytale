Mountain Fairytale 1.1.1

- Исправлен вход при недоступном API: ошибка соединения и кнопка «Повторить» показываются на экране авторизации.
- После восстановления связи можно повторить подключение и загрузить список пользователей без перезапуска приложения.
- Экран обязательного обновления появляется только при подтверждённой несовместимости версии.
- Временная недоступность API не закрывает рабочие формы и не сбрасывает несохранённые данные. Ошибка восстановления входа не удаляет сохранённую авторизацию.

Совместимость с backend 1.0.0 сохранена. Обновление backend и повышение минимальной версии Flutter для этого исправления не требуются.
